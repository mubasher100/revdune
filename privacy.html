Privacy policy

Last updated: 30 October 2026

"RevDune Uploader" is a private tool used only by the owner of the RevDune channel to publish the channel's own videos. It is not offered to the public, and no one else can sign in to it.

What it accesses

With the channel owner's permission, the tool uses the YouTube API Services to:

  • upload videos, titles, descriptions and tags to the owner's own channel;
  • read the channel's own video statistics (views, watch time, likes) to see which videos perform best.

It does not read, collect or store data about viewers or any other YouTube user.

Where data is kept

The access token Google issues is stored only on the owner's own computer, in the Windows Credential Manager. Channel statistics are kept in a local database on that computer. Nothing is sold, shared with third parties or used for advertising.

Removing access

Access can be revoked at any time from the Google account's security settings: myaccount.google.com/permissions. Revoking it stops all uploads and statistics requests; locally stored statistics can be deleted on request.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's use of data is described in the Google Privacy Policy.
